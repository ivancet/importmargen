# ImportMargen (beta)
Calculadora de margen y puja máxima para compraventas que importan coches usados de NL/DE/BE/FR a España.
HTML + CSS + JS estático, sin backend ni tracking; los datos se guardan en el navegador.

**Beta — cifras orientativas, consulte a su gestoría. No es asesoramiento fiscal.**

Tests: `node tests/calc.test.js`
